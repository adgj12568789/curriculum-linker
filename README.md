# 교과연계 기록 v9

날짜·교시·학년·과목을 선택하면 해당 날짜의 주차와 교과연계 파일의 성취기준을 찾고, 실제 활동 시간대와 연결하여 교과연계 문장을 작성합니다.

## v9 변경점
- 활동과 성취기준이 직접 겹치지 않아도 활동의 핵심 소재/행위에서 출발해 교과 개념으로 최대한 자연스럽게 연결
- 특히 이동·교통·체험·관람·시장·평화공원 등도 합리적인 개념적 연결을 먼저 탐색
- 계획서의 성취기준 / 교수학습 활동 / 평가 방법 / 시수·누계를 분리하여 사용
- Gemini 실패 또는 API 키 미설정 시에도 규칙 기반 연결 문장 생성
- 맞춤법·띄어쓰기·메타 표현 자동 정리
