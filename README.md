# 교과연계 기록 v4

중학교 1·2·3학년을 대상으로, 날짜·교시·학년·과목을 선택하면 업로드한 학년별 교과 운영·평가 계획서의 해당 주차 성취기준과 일정표 활동을 자동 연결하는 웹앱입니다.

## 핵심 흐름
1. 교과연계 파일 탭에서 학년별 계획서를 여러 개 업로드합니다. 파일은 IndexedDB에 유지됩니다.
2. 활동 설정 탭에서 현장학습·행사·수업 일정표를 원문 그대로 붙여 넣고 AI로 자동 정리합니다.
3. AI 결과에서 날짜/시간/시간(분)/활동 탭/세부 일정을 검토한 뒤 저장합니다.
4. 학교별 1~7교시 실제 시작·종료 시간을 설정합니다.
5. 자동 연계에서 날짜·교시·학년·과목을 선택하면 해당 교시와 겹치는 일정의 주요 활동과 그 주차의 성취기준을 자동으로 찾습니다.
6. Gemini가 성취기준 코드·성취기준·교과 내용·활동을 바탕으로 교과연계 계획 문구를 작성합니다.

## Vercel 환경변수
`GEMINI_API_KEY`를 Vercel Project Settings → Environment Variables에 등록합니다.
필요하면 `GEMINI_MODEL`을 별도로 지정할 수 있으며 기본값은 `gemini-2.5-flash`입니다.
