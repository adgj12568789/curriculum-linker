# 교과연계 기록 v11

중학교 1·2·3학년의 학년별 교과 운영·평가 계획서를 여러 개 저장하고, 날짜·교시·학년·과목을 선택하면 해당 주차의 성취기준과 일정 활동을 연결해 짧은 교과연계 문구를 작성하는 웹앱입니다.

## v11 주요 수정
- PDF/엑셀에서 `10월`과 `3주`가 서로 다른 줄·셀에 있어도 `10월 3주차`로 복원
- `9월 5주~10월 1주` 같은 범위 인식 강화
- 기존 저장 계획서는 parserVersion 11로 자동 재분석
- 1·2·3학년 사회/역사 파일의 파일명 기반 학년·과목 자동 감지 유지
- 성취기준 코드와 성취기준을 병합 셀에서 다음 주차로 상속

## 배포
GitHub 저장소에 index.html, api 폴더, vercel.json을 올리고 Vercel에 연결합니다.

- GEMINI_API_KEY
- GEMINI_MODEL (선택)
