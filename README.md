# 교과연계 기록 웹앱

중학교 1·2·3학년 교사가 학년별 교과 운영·평가 계획서를 여러 개 저장하고, 날짜·교시·학년·과목을 고르면 해당 주차의 성취기준 코드와 교과 내용을 찾아 등록해 둔 활동과 연결하는 웹앱입니다.

## 주요 기능
- 계획서 **다중 파일 업로드**: 한 번에 여러 개 선택 가능
- 계획서 파일별 저장/삭제/학년/과목 관리
- 기존 계획서를 새 파일 업로드 때문에 덮어쓰지 않음
- 날짜로 월 주차 자동 계산
- 활동 시간표 일괄 입력 및 활동 파일 가져오기
- 활동 유형별 탭 관리
- 주차·학년·과목에 따른 성취기준 자동 매칭
- 교과연계 문구 생성 후 직접 수정 가능
- 활동별 기록 탭
- IndexedDB에 계획서·활동·기록 저장
- PDF/XLSX/XLS/DOCX/CSV/TXT 지원

## 활동 입력 형식
탭으로 구분:

`요일[TAB]교시[TAB]학년[TAB]과목[TAB]활동내용[TAB]활동탭`

마지막 `활동탭`은 선택입니다.

예:

`월    1    1    사회    자료를 읽고 핵심 개념을 정리하는 활동    자료 분석`

## 계획서 저장
- 같은 브라우저에 계속 저장됩니다.
- 기존 계획서를 지우지 않는 한 유지됩니다.
- 새 파일을 올리면 기존 파일에 **추가**됩니다.
- 파일별로 기본 학년/과목을 수정할 수 있습니다.
