# 교과연계 기록 웹앱

날짜와 교시를 선택하면 학교 교시 시간대와 등록된 활동 일정을 비교하고, 해당 날짜의 주차와 학년·과목에 맞는 교과 운영·평가 계획서의 성취기준을 찾아 교과연계 계획을 작성합니다.

## 주요 기능
- PDF/XLSX/XLS/DOCX/CSV/TXT 교과 운영·평가 계획서 다중 업로드
- 주차 자동 판별 및 병합 셀 성취기준 상속
- 실제 학교 교시 시간대와 활동 일정 겹침 자동 계산
- 활동 원문 붙여넣기 → AI 일정 정리 → 탭별 관리
- 교과연계 문구 자동 작성 + 맞춤법·띄어쓰기 검수
- 계획서·활동·기록 브라우저 저장

## Vercel 환경변수
- `GEMINI_API_KEY`: Google AI Studio API 키
- `GEMINI_MODEL`: 선택 사항. 기본값 `gemini-3.8-flash`
