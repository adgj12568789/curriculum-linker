# 교과연계 기록 v6

## 이번 버전의 핵심 수정
- PDF.js가 PDF 표를 한 줄로 뭉개지 않고 화면의 세로 위치를 기준으로 줄 단위로 복원합니다.
- `9월 5주~10월 1주` 같은 범위를 두 주차 모두에 매칭합니다.
- 표에서 성취기준 코드/성취기준/단원명이 병합 셀로 한 번만 적힌 뒤 다음 주차가 비어 있어도 자동 상속합니다.
- 군외중 2학년 역사과 계획서의 `10월 4주` 같은 연속 행도 앞 주차의 `[9역06-01]`을 이어받아 검색할 수 있도록 수정했습니다.
- 단원/소단원은 `교과 내용`으로 정리합니다.
- v5에서 이미 저장된 계획서는 rawPreview가 있으면 최초 실행 시 자동 재분석을 시도합니다.
- 1~3학년, 7교시(09:00 시작 / 45분 수업 / 10분 쉬는 시간 / 점심 12:30~13:15) 기본값을 유지합니다.
