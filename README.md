# 교과연계 기록

중학교 1·2·3학년 교사가 학년별 교과 운영·평가 계획서를 한 번 업로드하고, 날짜/교시/학년/과목/활동을 선택하면 해당 주차의 성취기준 코드·성취기준·교과 내용을 찾아 활동과 연결된 교과연계 문구를 작성하는 웹앱입니다.

## 구성
- `index.html` : 전체 웹앱. 별도 빌드 없이 Vercel에 배포 가능
- `api/generate-linkage.js` : Gemini AI 호출용 Vercel 서버리스 함수. API 키를 브라우저에 노출하지 않음

## 지원 파일
PDF / XLSX / XLS / DOCX / CSV / TXT

스캔 이미지 PDF는 텍스트 추출이 되지 않을 수 있습니다. 가능하면 텍스트가 선택되는 PDF나 XLSX/DOCX를 사용하세요.

## 저장 방식
계획서, 활동 시간, 활동 기록은 브라우저 IndexedDB에 저장합니다. 웹앱을 새로고침하거나 다시 방문해도 같은 브라우저에 저장된 내용은 유지됩니다. 계획서를 새로 업로드하거나 삭제하기 전까지 기존 계획서를 사용합니다.

## 활동 일괄 입력
활동 설정 탭에서 다음 형식으로 붙여넣습니다.

`요일[TAB]교시[TAB]학년[TAB]과목[TAB]활동내용`

예:

`월  1  1  사회  자료를 읽고 핵심 개념을 정리하는 활동`

## 주차 계산
월의 첫날이 어느 요일인지 고려하여 학교에서 쓰기 편한 '월 1주차, 월 2주차' 방식으로 계산합니다.

예를 들어 2026년에는
- 9월 28~30일 → 9월 5주차
- 10월 1~2일 → 10월 1주차
- 10월 5~9일 → 10월 2주차

## Vercel + Gemini
Vercel 프로젝트의 Environment Variables에 다음을 등록합니다.

- `GEMINI_API_KEY` : Google AI Studio API key
- `GEMINI_MODEL` : 선택사항. 기본값 `gemini-3.8-flash`

Gemini 키는 `index.html`에 넣지 않습니다.

## 사용 흐름
1. 계획서 탭에서 학년별 교과 운영·평가 계획서를 한 번 업로드합니다.
2. 활동 설정 탭에서 시간표별 활동을 일괄 입력합니다.
3. 자동 연계 탭에서 날짜·교시·학년·과목을 선택합니다.
4. 해당 날짜의 주차와 활동이 자동으로 잡힙니다.
5. 계획서에서 해당 주차의 성취기준 코드·성취기준·교과 내용이 표시됩니다.
6. '교과연계 자동 작성'으로 기록 문구를 만듭니다.
7. 활동 기록에 저장하면 활동별 탭에서 다시 볼 수 있습니다.
