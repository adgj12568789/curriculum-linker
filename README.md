# 교과연계 기록 v10

중학교 1·2·3학년 대상 교과연계 기록 웹앱입니다.

주요 기능:
- 여러 학년·과목의 교과 운영 및 평가 계획서 저장
- 주차 자동 판별 및 병합 셀 성취기준 상속
- 일정표 원문 붙여넣기 → AI 일정 정리
- 교시별 실제 시간대와 활동 자동 매칭
- 성취기준 코드/성취기준/교과 내용을 분리해 사용
- 활동의 소재 → 교과 개념 → 성취기준 의미 순으로 간결한 교과연계 문장 생성
- 교과연계 문장은 50자 안팎, 최대 60자를 목표로 하며 맞춤법/띄어쓰기 검수
- 결과는 브라우저 IndexedDB에 저장

Vercel Environment Variable:
- GEMINI_API_KEY
- GEMINI_MODEL (optional)
